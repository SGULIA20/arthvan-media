# arthvan-media: read before acting

App promotion (ScoreMyBiz, Waypoint), the founder's daily LinkedIn post and the Telegram bot. The same founder runs sg-content,
ScoreMyBiz and Waypoint; sessions run on the Mac (VS Code), the phone and in the cloud, so the repos are the shared memory.

1. Start with `git pull --ff-only`. If it fails, or `git status` shows unsaved work, stop and tell the founder before changing anything.
2. Read the shared founder decisions: SGULIA20/sg-content `docs/decisions.md` (on the Mac: ~/sg-content/docs/decisions.md). Follow them.
3. Read `git log --oneline -15` to see what changed recently and why.
4. When the founder settles something new, add one line to that decisions file. Commit messages say why.
5. Picture styles per app live in `content/brand_styles.json`. Times told to the founder are in WAT. Push only with the founder's yes.
